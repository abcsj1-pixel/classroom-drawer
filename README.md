# 교실 서랍

웹앱 모음집과 학생들에게 크게 보여 주는 쉬는시간 타이머입니다. 별도 패키지 설치 없이 작동하는 HTML/CSS/JavaScript 앱입니다.

## GitHub Pages와 클라우드 일기장

허브: https://abcsj1-pixel.github.io/classroom-drawer/

일기장: https://abcsj1-pixel.github.io/classroom-drawer/diary/

Firebase Authentication의 Google 로그인과 Cloud Firestore를 사용합니다. 로그인 사용자는 본인의 일기만 읽고 수정합니다. 로컬 일기장 데이터는 자동으로 업로드하거나 가져오지 않습니다. 기존 기록은 ‘하루의 조각 · 로컬’ 카드로 계속 사용할 수 있습니다.

로그인 상태는 탭 세션에서만 유지하고 일기 오프라인 영구 저장은 사용하지 않습니다. 공용 기기에서는 로그아웃하고 브라우저를 닫으세요. 검색·달력·내려받기는 현재 불러온 기록에 적용되며, ‘이전 기록 더 불러오기’로 200개씩 추가합니다.

[공개 전 보안·개인정보 검토](docs/보안검토.md)를 읽어 주세요. 공개 웹 설정은 관리용 비밀키가 아니며, `firestore.rules`가 데이터 접근을 제한합니다.

개발·재빌드: Node.js 24.12 이상에서 `npm ci --ignore-scripts`, `npm test`, `npm run build`. `pages-output`은 허용된 정적 파일만 담는 생성 디렉터리입니다. GitHub Pages 게시 소스는 `gh-pages` 브랜치의 루트이며, 업데이트할 때 소스 변경과 다시 빌드한 이 디렉터리를 각각 게시합니다. GitHub OAuth의 workflow 권한을 추가 요청하지 않도록 기본 브랜치 게시 방식을 사용했습니다.

Firestore 규칙 테스트: Java 21 이상과 Firebase CLI를 준비한 뒤 `npx -y firebase-tools@latest emulators:exec --only firestore --project demo-day-pieces "npm run test:rules"`. 실제 사용자 데이터는 사용하지 않습니다.

## 내 컴퓨터에서 실행

`교실 서랍 시작.command`를 더블클릭합니다. Python 3가 필요합니다. 허브가 http://127.0.0.1:8780 에서 열립니다. 터미널을 종료하면 서버도 종료됩니다.

바로 옆 `로컬 서버 일기장` 폴더의 기존 서버를 함께 실행합니다. 기존 일기 파일을 옮기거나 복사하지 않습니다. 일기장이 이미 8765번 포트에서 실행 중이면 그대로 연결합니다. 다른 포트로 일기장을 실행했다면 ‘웹앱 추가’로 해당 로컬 주소를 추가하세요. 개인 공간의 일기장 카드에서 안내를 확인하고 기존 일기장을 엽니다.

허브만 실행: `python3 launch.py --no-diary`. 브라우저 자동 열기 없이 실행: `python3 launch.py --no-browser --no-diary`.

## 포함된 앱

- 쉬는시간 타이머: 새로 구현. `#timer` 주소로 직접 열기, 5/10/15/20분, 1–180분 직접 입력, 일시정지·이어가기·초기화, 전체화면, 시각 종료 안내와 선택 알림음. 지원 브라우저에서는 실행 중 화면 잠금을 방지합니다. 탭이 비활성화되어도 시각 기준으로 계산합니다. 브라우저·기기 절전 중 소리 재생은 브라우저 정책에 따라 제한될 수 있습니다.
- 마음말: 기존 공개 AAC 앱으로 연결.
- 알라르간도: 기존 공개 영상 기억 방탈출 앱으로 연결.
- 레피숭이의 경경화 체크: 기존 공개 재미 테스트로 연결.
- 하루의 조각: Firebase 클라우드 일기장. Google 계정 로그인 후 사용합니다.
- 하루의 조각 · 로컬: 기존 로컬 일기장으로 연결. 이 컴퓨터에서 기존 서버가 실행 중이어야 합니다.

이름 입력이 명시된 친구마을, 학생 개인정보를 다루는 기록 앱, 아직 게시되지 않은 소곤소곤은 기본 목록에서 제외했습니다. 기존 공개 앱의 소개와 게시 상태를 확인하여 링크를 등록했으며, 해당 앱들의 데이터 처리 전체를 감사한 것은 아닙니다. 허브에는 기존 앱의 사용자 데이터나 서버를 합치지 않았습니다.

## 저장·공유

허브의 즐겨찾기와 직접 추가한 링크는 브라우저 localStorage에만 저장합니다. 기기·브라우저·주소가 다르면 별도로 저장됩니다. 브라우저 데이터 삭제 시 사라지며 다른 사용자와 자동 공유되지 않습니다. 허브는 일기 내용을 읽지 않습니다. 클라우드 일기장 페이지는 로그인 후 일기 데이터를 Firebase로 전송합니다. 비밀키·접근 토큰이 담긴 URL은 등록하지 마세요. 외부 앱은 새 탭에서 열리며 각 앱의 데이터 처리는 해당 앱에 따릅니다.

기본 목록 변경: `dist/apps.mjs` 수정. 웹 화면의 ‘웹앱 추가’는 해당 브라우저에만 추가합니다. 개인정보가 없는 링크만 수동으로 추가하세요. 학생용 타이머 화면에는 일기장 카드가 표시되지 않습니다. 화면 분리는 인증 수단이 아니며, 호스팅 사이트의 공개 범위는 별도의 접근 설정에 따릅니다.

## 검증

Node.js 24.12 이상에서 `npm test` 또는 `node --test tests/*.test.mjs`. 타이머 지연·중지·재개·완료·시간 검증, 주소 검증, 검색·필터·즐겨찾기와 일기장 입력·세션 보호를 검사합니다. 로컬 서버는 `dist`만 정적으로 제공하므로 상위 일기장 파일을 제공하지 않습니다.

## 호스팅

현재 공개 배포는 GitHub Pages입니다. 이전 Sites 개인 게시와는 별개의 배포이며, Sites 메타데이터는 GitHub에 포함하지 않습니다. Python 런처와 일기 데이터는 웹 배포 파일에 넣지 않습니다. 타이머는 학생 각자의 기기에 동기화되는 방식이 아니라 현재 화면에서 실행됩니다.
