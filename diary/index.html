일기를 저장하기 전에

Google 로그인은 계정 식별에 필요한 이메일·이름·계정 ID를 Firebase Authentication에서 처리합니다. 이름과 이메일을 일기 문서에 복사하지 않아요.

일기 날짜·제목·본문·기분·생성 및 수정 시각은 Google Cloud Firestore에 로그인 사용자별 경로로 저장합니다. 다른 사용자에게 공개하는 기능은 없으며 광고·방문 분석 기능을 넣지 않았어요. 운영 권한이 있는 Firebase 프로젝트 관리자는 데이터에 접근할 수 있습니다. 종단간 암호화 서비스는 아닙니다.

브라우저에는 일기 오프라인 영구 저장을 사용하지 않습니다. 로그인 상태는 현재 탭 세션에서 유지합니다. 로그아웃 시 화면의 일기를 비우고 페이지를 다시 읽습니다. 내려받은 파일은 기기에 남으므로 직접 관리해 주세요.

기록은 직접 삭제할 때까지 보관됩니다. 각 일기의 삭제 버튼으로 지울 수 있으며, 계정 자체와 전체 데이터 삭제 요청은 프로젝트 운영자에게 문의하세요. 학생 개인정보나 민감한 제3자 정보를 기록하는 용도로 제공하지 않습니다.
